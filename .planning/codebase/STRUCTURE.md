## Directory Purposes

**public/:**
- Purpose: Static files served directly; HTML template for React mount
- Contains: index.html (contains `<div id="root">` where App mounts), favicon, manifest, asset references
- Key files: `public/index.html`

**src/:**
- Purpose: All React source code
- Contains: Main App component, styling, tests, entry point
- Key files: `src/App.js` (main logic), `src/index.js` (entry point)

**build/:**
- Purpose: Output directory for production build (generated by `npm run build`)
- Generated: Yes
- Committed: No (in .gitignore)

**node_modules/:**
- Purpose: Installed npm packages
- Generated: Yes (by `npm install`)
- Committed: No (in .gitignore)

## Naming Conventions

**Files:**
- `.js`: React components and logic
- `.css`: Stylesheets
- `.test.js`: Test files (Jest convention)
- Casing: camelCase for variables, PascalCase for components and constants

**Directories:**
- lowercase: `src/`, `public/`, `build/`, `node_modules/`

**Functions:**
- camelCase: `handleSearch()`, `evaluateProgram()`, `formatProgramDetailed()`
- PascalCase: `App()` (React component)

**Variables:**
- Constants (uppercase + underscores): `SEED_LENDERS`, `SEED_PROGRAMS`, `LOAN_TYPES`, `STATES`, `EMPTY`
- State variables (camelCase): `scenario`, `results`, `view`, `customPrograms`
- React hooks follow camelCase: `setView()`, `setScenario()`

**Types/Patterns:**
- Objects: `scenario`, `program`, `EMPTY` (template object)
- Arrays: SEED_LENDERS[], SEED_PROGRAMS[], customPrograms[]
- Maps/Objects for lookup: `lenderNames`, `ltvMap`, `wm` (derogatory waiting map)

## Where to Add New Code

**New Feature (e.g., export results to PDF):**
- Primary code: `src/App.js` (add handler function and button to UI)
- Consider: If logic becomes complex, extract to `src/lib/export.js`
- Tests: `src/App.test.js` (add test for new handler)
- Example: Add `handleExportPDF()` function, integrate with results view

**New Component (e.g., separate SearchForm):**
- Implementation: Create `src/components/SearchForm.js`
- Pass props: scenario, setScenario, onSearch callback
- Usage: Import and render in App.js
- Tests: `src/components/SearchForm.test.js`

**New Utilities (e.g., program filtering, validation):**
- Shared helpers: `src/lib/matching.js` or `src/utils/evaluation.js`
- Example: Extract `evaluateProgram()` to `src/lib/matching.js`, import in App.js
- Keep pure functions; no React dependencies

**Data Updates:**
- Add/modify programs: Edit SEED_PROGRAMS array in `src/App.js` (lines 3–816)
- Better approach: Move to JSON file (`src/data/programs.json`), import at startup

**Styling Updates:**
- Global styles: `src/index.css`
- Component styles: Add to `src/App.css` or keep inline in JSX
- Recommendation: Consider CSS modules or Tailwind if styles grow beyond current approach
