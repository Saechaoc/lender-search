## VA Encoding Strategy (B4a)

Per Codex review (B4): a flat 24-month VA foreclosure wait without conditions is a **typical lender/investor overlay**, NOT VA agency base. VA Pamphlet 26-7 is more conditional (entitlement, re-established credit, deed-in-lieu, short sale, second-tier-entitlement all factor in). Encoding overlay-shaped rules as `AGENCY_BASE` undermines the entire layer model that Phase 4's evaluator depends on.

**B4a resolution:** Audit each VA event_type rule against VA Pamphlet 26-7 Chapter 4 Topic 7. A rule is encoded ONLY if:
1. It has a specific, citable section in VA Pamphlet 26-7 documenting an unconditional waiting period (independent of entitlement / credit re-establishment status), AND
2. The cited section can be linked via a deep URL anchor that survives manual verification.

Rules that fail either gate are listed in this plan's `## Deferred` section and are NOT seeded. Phase 4's evaluator MUST handle missing event_type rows via the same fall-through semantic B9 establishes.

## Cited Rules (encoded as AGENCY_BASE)

Per `## Deferred` section below, the planner verifies each rule's citability against VA Pamphlet 26-7 BEFORE this plan merges. Manually-verified candidates (subject to confirmation):

- **BK7:** 24m base from discharge — VA Pamphlet 26-7 Ch4 Topic 7 explicitly cites a 24-month BK7 waiting period. **Likely citable.**
- **BK13_DISCHARGED:** 24m from discharge — same chapter; VA explicitly notes 12 months pay-out + trustee approval as alternative path. **Likely citable.**
- **BK13_DISMISSED:** 24m from dismissal — same chapter. **Likely citable.**
- **MULTIPLE_BK:** Encoded as explicit `not_applicable=true` row per B9. VA does not separately specify multi-filing; the row is a sentinel for evaluator missing-rule semantics.
- **FORECLOSURE:** Encoded as **explicit `not_applicable=true` row** per AGY-05 + B9 (iter-2 REVIEWS resolution). VA does not impose a flat 24-month wait — the 24m commonly seen in market is a lender/investor overlay, not VA agency base. A nuanced VA-specific rule (no waiting for new entitlement; conditional on re-established credit) requires Phase 4 evaluator support that does not exist yet. The `not_applicable=true` sentinel makes VA's "no separately specified rule" stance explicit so AGY-05 has a queryable row AND Phase 4 evaluator can deterministically fall back to FNMA/FHLMC paths.
- **DEED_IN_LIEU:** **`not_applicable=true`** — same reasoning as FORECLOSURE.
- **SHORT_SALE:** **`not_applicable=true`** — same reasoning.
- **MORTGAGE_CHARGE_OFF:** **`not_applicable=true`** — VA Pamphlet 26-7 does not separately specify mortgage charge-off; lenders treat it as foreclosure-equivalent (their overlay, not VA base).

**Total seeded rows under VA-PAM-26-7-Ch4: 8 (3 BK rules with citations + 5 explicit `not_applicable=true` sentinels: MULTIPLE_BK / FORECLOSURE / DEED_IN_LIEU / SHORT_SALE / MORTGAGE_CHARGE_OFF).** The 5 sentinel rows satisfy AGY-05's "VA derog matrix encoded as queryable rows" requirement WITHOUT violating layer discipline — every row is either a cited VA rule OR an explicit `not_applicable=true` marker. This addresses iter-2 REVIEWS B4a regression: the prior "deferral" approach left AGY-05 with no rows for those event types; the sentinel approach gives Phase 4 evaluator deterministic fall-through semantics.

The acceptance criterion below explicitly asserts EVERY VA `agency_rule` row has a non-null citation pointing to a specific VA Pamphlet 26-7 section URL.

## Sentinel Encoding (not deferred — AGY-05 coverage with explicit not_applicable)

Iteration-2 REVIEWS B4a regression resolution: rather than "defer" 4 event types (which left AGY-05 uncovered for VA), encode each as an explicit `not_applicable=true` row. This satisfies AGY-05 ("VA derog rules encoded as queryable rows") AND respects layer discipline (no flat 24m wait encoded as agency base):

| event_type | Encoding | Rationale |
|------------|----------|-----------|
| FORECLOSURE | `not_applicable=true` sentinel | VA imposes no flat waiting after FC for new entitlement; the 24m commonly seen is typical lender overlay. Phase 4 evaluator falls back to FNMA/FHLMC. |
| DEED_IN_LIEU | `not_applicable=true` sentinel | Same reasoning as FORECLOSURE. |
| SHORT_SALE | `not_applicable=true` sentinel | Same reasoning. |
| MORTGAGE_CHARGE_OFF | `not_applicable=true` sentinel | VA does not separately specify; lenders treat as foreclosure-equivalent. |

**Recovery path:** After Phase 4 ships entitlement-aware evaluation (or after a future overlay phase encodes these rules under `LENDER_OVERLAY` / `INVESTOR_OVERLAY`), the sentinel rows can be replaced with rule-bearing rows in a follow-up `agency_rule_version`. Phase 4 evaluator's missing-event_type fall-through semantic (per B9) ensures scenarios for these event types evaluate against the more permissive FNMA / FHLMC paths until VA-specific entitlement modeling lands.
