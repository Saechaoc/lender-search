# Plan 03-04: FHA HUD 4000.1 derog matrix + Back-to-Work DEPRECATED + USDA stub fold-in

## Objective

Hand-author the FHA HUD 4000.1 §II.A.5.b derog waiting-period matrix (8 active event types with FHA's shorter timings) AND ship the FHA Back-to-Work program as a separate `agency_rule_version` row with `effective_period = '[2013-08-15,2016-09-30)'` so it remains queryable for historical replay but is filtered from `effective_period @> CURRENT_DATE` lookups (Phase 3 SC#4 + Pitfall 1.4).

This plan satisfies Phase 3 SC#4 explicitly:
> "FHA HUD 4000.1 standard extenuating-circumstances provision is encoded; FHA Back-to-Work is marked `DEPRECATED` with `sunset: 2016-09-30` and is queryable but not active."

Per RESEARCH §"Per-agency content matrix" §FHA HUD 4000.1 (FHA's shorter timings vs FNMA/FHLMC):
- **BK7:** 24m base, 12m EC, anchor=DISCHARGE
- **BK13_DISCHARGED:** 24m base, anchor=DISCHARGE (12m if currently in pay-out plan with trustee approval — Phase 3 ships discharge variant; trustee-approval variant deferred per Open Question 5)
- **BK13_DISMISSED:** 24m base, 12m EC, anchor=DISMISSAL
- **MULTIPLE_BK:** SKIP per Open Question 5 (FHA defers to standard EC; document in fixture comment)
- **FORECLOSURE:** 36m base, 12m EC (standard EC active), anchor=COMPLETION
- **DEED_IN_LIEU:** 36m base, 12m EC, anchor=COMPLETION
- **SHORT_SALE:** 36m base, 12m EC, anchor=SALE_CONFIRMATION
- **MORTGAGE_CHARGE_OFF:** 36m base, 12m EC, anchor=CHARGE_OFF_DATE (mortgage_included_in_bk_rule = 'NOT_APPLICABLE')

Plus:
- **Back-to-Work DEPRECATED:** Separate `agency_rule_version` row with `agency='FHA'`, `version_label='HUD-4000.1-BTW-DEPRECATED'`, `effective_period='[2013-08-15,2016-09-30)'`, `superseded_by` left NULL (Back-to-Work was retired by Mortgagee Letter 2016-14, not superseded by another version). Plus a single `agency_rule` row of `rule_kind='derog_seasoning'` describing the 12-month-post-FC reduced waiting period that Back-to-Work permitted, with citation pointing at Mortgagee Letter 2016-14 (Assumption A6 — planner verifies the exact ML number against HUD's archive).

Per Assumption A6 (Mortgagee Letter 2016-14 vs 2016-09): planner verifies the exact ML number BEFORE merging this plan. The DEPRECATED state + sunset_date is what matters for Phase 3 SC#4; the ML number is documentation.
