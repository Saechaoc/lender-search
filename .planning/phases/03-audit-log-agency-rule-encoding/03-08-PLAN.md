# Plan 03-08: Phase 3 integration gate — BLOCKING full-suite verification

## Objective

Phase 3's exit gate. After all 7 prior plans land, this plan runs the full reset → migrate → seed → test:rls → test:schema → typecheck → lint sequence end-to-end as a single [BLOCKING] task and confirms every Phase 3 success criterion is empirically green. Mirrors the Phase 1 Plan 01-08 + Phase 2 Plan 02-07 [BLOCKING] integration gate convention.

This plan adds NO new artifacts — every file is already in place from Plans 03-01 through 03-07. The single task here is the integration gate: a clean-room build of Phase 3 from a fresh DB through the full test surface, plus a final human-verify checkpoint reviewing the post-seed counts and the cascade trigger end-to-end behavior.

If any step fails, the failure points back to one of Plans 03-01..03-07 — the gap-closure path is `/gsd-plan-phase --gaps` against this plan's verification output.

    # 6e — REVOKE state on evaluation_event parent + child partitions (AUD-03 + Pitfall PG-2)
    docker compose exec -T postgres psql -U postgres -d lender_search_dev -c "
      SELECT
        c.relname,
        has_table_privilege('app_user', c.oid, 'UPDATE') AS app_update,
        has_table_privilege('app_user', c.oid, 'DELETE') AS app_delete,
        has_table_privilege('system_role', c.oid, 'UPDATE') AS sys_update,
        has_table_privilege('system_role', c.oid, 'DELETE') AS sys_delete
      FROM pg_class c
      WHERE c.relname LIKE 'evaluation_event%'
      ORDER BY c.relname;
    "

    # 6f — cascade trigger + function presence (AGY-08 + Phase 3 SC#5)
    docker compose exec -T postgres psql -U postgres -d lender_search_dev -c "
      SELECT proname FROM pg_proc
      WHERE proname IN ('create_next_evaluation_event_partition', 'enqueue_agency_cascade')
      ORDER BY proname;
    "
    docker compose exec -T postgres psql -U postgres -d lender_search_dev -c "
      SELECT tgname FROM pg_trigger
      WHERE tgname = 'agency_rule_version_cascade';
    "

    docker compose exec -T postgres psql -U postgres -d lender_search_dev -c "
      SELECT relname, relrowsecurity, relforcerowsecurity FROM pg_class
      WHERE relname IN ('evaluation_event', 'cascade_review_queue')
      ORDER BY relname;
    "

    # 6h — Phase 3 EXCLUDE constraints (AGY-09 D-20)

      SELECT conname, pg_get_constraintdef(oid)
      FROM pg_constraint
      WHERE conname IN ('conforming_loan_limit_version_no_overlap')
      ORDER BY conname;
    "
