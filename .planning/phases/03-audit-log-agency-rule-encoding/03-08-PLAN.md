# Plan 03-08: Phase 3 integration gate — BLOCKING full-suite verification

## Objective

Phase 3's exit gate. After all 7 prior plans land, this plan runs the full reset → migrate → seed → test:rls → test:schema → typecheck → lint sequence end-to-end as a single [BLOCKING] task and confirms every Phase 3 success criterion is empirically green. Mirrors the Phase 1 Plan 01-08 + Phase 2 Plan 02-07 [BLOCKING] integration gate convention.

This plan adds NO new artifacts — every file is already in place from Plans 03-01 through 03-07. The single task here is the integration gate: a clean-room build of Phase 3 from a fresh DB through the full test surface, plus a final human-verify checkpoint reviewing the post-seed counts and the cascade trigger end-to-end behavior.

If any step fails, the failure points back to one of Plans 03-01..03-07 — the gap-closure path is `/gsd-plan-phase --gaps` against this plan's verification output.
