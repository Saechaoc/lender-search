# Plan 03-02: FNMA B3-5.3-07 derog matrix — full event-type parity + golden snapshot

## Objective

Hand-author the full FNMA Selling Guide B3-5.3-07 derogatory waiting-period matrix (8 event types) as a TypeScript fixture at `lib/agency-seeds/fnma/derog-seasoning.ts`, register the FNMA seed call in `scripts/seed-agency.ts main()`, and ship per-event-type structural assertions plus a golden snapshot regression test at `tests/agency/fnma-derog.test.ts`. Also creates the cross-agency `tests/agency/agency-version.test.ts` covering AGY-01 (one `agency_rule_version` row per agency post-seed; this Wave 1 plan covers FNMA + USDA assertions, with placeholder it.todo() rows for FHLMC/FHA/VA that the sibling Wave 1 plans flesh out).

Phase 3 SC#3 is the gate this plan enforces structurally:
- **BK7:** 48m base, 24m EC, anchor=DISCHARGE
- **BK13_DISCHARGED:** 24m, no EC, anchor=DISCHARGE
- **BK13_DISMISSED:** 48m base, 24m EC, anchor=DISMISSAL
- **MULTIPLE_BK:** 60m base, 36m EC, anchor=DISCHARGE (Pitfall 1.5 — 5y from most recent discharge)
- **FORECLOSURE:** 84m base, 36m EC, anchor=COMPLETION + `post_event_LTV_caps[0] = {months_since_min:36, months_since_max:84, max_LTV:90, purposeAllowList:['PURCHASE','RATE_TERM_REFI'], occupancyAllowList:['PRIMARY']}` (Phase 3 SC#3 + Pitfall 1.2)
- **DEED_IN_LIEU:** 48m base, 24m EC, anchor=COMPLETION
- **SHORT_SALE:** 48m base, 24m EC, anchor=SALE_CONFIRMATION
- **MORTGAGE_CHARGE_OFF:** 48m base, 24m EC, anchor=CHARGE_OFF_DATE + `mortgage_included_in_bk_rule = 'BK_CLOCK_APPLIES_IF_NOT_REAFFIRMED'` (Pitfall 1.6)

URL-only citations under SYSTEM tenant per D-07.

    import { createHash } from 'node:crypto';
    import { describe, expect, it } from 'vitest';

    interface FnmaRuleBody {
      event_type: string;
      measurement_anchor: string;
      base_waiting_months: number;
      extenuating_circumstances_waiting_months: number | null;
      post_event_LTV_caps: Array<{
        months_since_min: number;
        months_since_max: number | null;
        max_LTV: number;
        purposeAllowList: string[];
        occupancyAllowList: string[];
      }>;
      mortgage_included_in_bk_rule: string;
    }

    async function fetchFnmaRule(eventType: string): Promise<FnmaRuleBody> {
      const adminClient = await globalThis.__pgAdminPool.connect();
      try {
        const { rows } = await adminClient.query<{ rule_body: FnmaRuleBody }>(
          `SELECT rule_body FROM agency_rule
            WHERE rule_kind = 'derog_seasoning'
              AND rule_body->>'event_type' = $1
              AND agency_rule_version_id = (
                SELECT id FROM agency_rule_version
                WHERE agency = 'FNMA' AND version_label = 'FNMA-SEL-2026-04'
                LIMIT 1
              )`,
          [eventType],
        );
        if (rows.length !== 1) {
          throw new Error(`Expected 1 FNMA ${eventType} row, got ${rows.length}`);
        }
        return rows[0]!.rule_body;
      } finally {
        adminClient.release();
      }
    }
