<objective>
Close the P1 cross-tenant rule_snapshot leak by promoting rule_snapshot to per-tenant scope (Option B). Same access pattern as program_version, evaluation_event, lender_overlay_rule: tenant_id NOT NULL column, tenant_isolation policy under FORCE RLS, app_user reads its own tenant's rows under the standard `app.tenant_id` setting.

Purpose: 0019 closed the immediate leak by gating reads to system_role only — but that locked in two architectural commitments we're rejecting: (1) Phase 4 evaluator running under a role transition just to read its own audit-replay snapshot, and (2) any future tenant-readable surface needing a brand-new RLS policy. Option B treats rule_snapshot like every other tenant-scoped table, so Phase 4 connects as `app_user` with `app.tenant_id` set and reads the snapshot under the same wall it uses for everything else.

Output: Migration 0022 + supporting code/test changes that make rule_snapshot's tenant boundary identical to program_version's. Two deferred-items notes captured for Phase 4 (re-adding the composite FK + connecting as app_user, NOT system_role) and the longer-term seed-pool posture.
</objective>

4. **Drop the existing UNIQUE on sha256_hash.** Drizzle auto-generates a name like `rule_snapshot_sha256_hash_unique` (uniqueIndex form) or `rule_snapshot_sha256_hash_key` (UNIQUE constraint form). Discover it dynamically inside a `DO` block — DO NOT hardcode:
   ```sql
   DO $$
   DECLARE
     idx_name text;
     con_name text;
   BEGIN
     -- Drop a unique INDEX form (Drizzle uniqueIndex(...).on(t.sha256Hash) emits this).
     SELECT indexname INTO idx_name
     FROM pg_indexes
     WHERE schemaname = 'public'
       AND tablename = 'rule_snapshot'
       AND indexdef ILIKE '%UNIQUE%'
       AND indexdef ILIKE '%sha256_hash%'
       AND indexdef NOT ILIKE '%tenant_id%';
     IF idx_name IS NOT NULL THEN
       EXECUTE format('DROP INDEX IF EXISTS public.%I', idx_name);
     END IF;

     -- Drop a unique CONSTRAINT form (in case Drizzle emitted a constraint instead).
     SELECT conname INTO con_name
     FROM pg_constraint
     WHERE conrelid = 'public.rule_snapshot'::regclass
       AND contype = 'u'
       AND pg_get_constraintdef(oid) ILIKE '%(sha256_hash)%';
     IF con_name IS NOT NULL THEN
       EXECUTE format('ALTER TABLE rule_snapshot DROP CONSTRAINT IF EXISTS %I', con_name);
     END IF;
   END $$;
   ```
